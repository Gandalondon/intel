Intel style guide

How Intel looks and behaves. Intel shows this week's Division 2 Manhunt tasks one at a time, on a phone propped beside the TV. Read this before changing a screen or the weekly copy. If something is missing, add it under Gaps rather than inventing a pattern.

The appPersonal Android app, built from Gandalondon/intel. GitHub builds an APK on every push, which Obtainium installs. Same pipeline as Hugin.
The contentOne small file per week, rewritten from the week's guides and committed to the repo every Tuesday. The app reads it when it opens, so new tasks never need a new build.
Source of truthThe live build wins over this guide. When they disagree, fix the guide.
House rulesUK English. No em dashes. No widows. Sentence case, never all caps. No eyebrows, labels or counters, except "Objective 1, 2, 3", which matches the game so the two can be checked side by side. One typeface, one task size. Spacing on the 8 px grid. £0 to run.
This filedocs/style-guide.html, built by tools/style-guide/make.py. Opens straight in a browser, offline.

Foundations

Taken from the game's menus: a dark ground, warm white text, and orange only as one solid block for the thing you act on, like the game's selected tile. No greys, no borders, no rounded corners.

Colour

Ground#141414 · --ground
Every background, the splash, the icon's cuts. A soft black, never #000.
Ink#F2EFEA · --ink
All task text. Never greyed down.
Orange#FF6C10 · --orange
The Continue block, the Objective label and the icon ring.
On orange#141414 · --on-orange
The Continue label.

Candidate: #EF8532, sampled from the game's Commendations screen, is softer and closer to the game's own UI. Not in use yet; see Gaps.

Type

Saira, tracking −1%: Regular (400) for task text, SemiBold (600) for the Objective label and Continue. Free (SIL Open Font Licence), bundled with the app, never loaded from Google Fonts. The game uses Borda, which needs a paid licence; Saira is the closest free match. Regular body with SemiBold labels chosen on 6 November 2026, after the game's own Manhunt screen: bold labels, regular copy you read.

One size for every task, so nothing jumps between steps. Write to fit: a task should stay under about 120 characters, which is nine lines on a phone and still clears the Continue block.

Space, size and shape

Grid8 px steps.
Margins24 px sides and bottom, 40 px above the task, plus the phone's safe areas.
ContinueFull width, 64 px tall (16 px padding top and bottom), label centred, 16 px gap above it. No pressed or hover effect: the screen changing is the feedback.
CornersSquare everywhere. The only round thing is the icon.
Shadows, linesNone in the app.

Logo and app icon

A thick orange ring cut by a black cross into four quarters. Straight vertical and horizontal cuts, nothing angled. A nod to the Division watch ring without copying it. The icon and the splash only: it never appears on the app's screens.

Launcher (circle)
Home-screen size
Geometry100-unit square. Ring radius 26, stroke 16. Cuts 9 units wide, through the centre, full height and full width. Ground #141414 behind.
NameIntel, plain text, sentence case. No wordmark lockup in the app.
NeverUbisoft's or The Division's logos, SHD marks or game art. Angled cuts, gradients, outlines or a second colour on the ring.

Writing a task

Each task is rewritten from the week's guides into one plain block, never pasted. Read it at a glance from the sofa.

Do

  • Lead with the verb and the count: "Do 3…", "Finish 1…", "Kill…".
  • Name the faction every time, so the map icon is easy to find.
  • Add a place or tip only when it saves time in game.
  • Check at least two guides and write what they agree on.

Don't

  • Capitals for emphasis, brackets, lists or labels.
  • Send him to one specific place when any will do.
  • Copy a guide's wording.
  • Go over about 120 characters.

Example: Red Horizon, Scout 11

  • Do 3 open-world activities held by Black Tusk: control points, hostage rescues, public executions, broadcasts or convoys.
  • Finish 1 Invaded Mission. Any main mission where Black Tusk have taken over counts.
  • Kill Eagle Eye, the Black Tusk bounty in West End. Take out his drones first.
  • Done: "Done. Next intel drops Tuesday."

Motion

Only the splash fading out, 300 ms. Text never animates. Reduced motion: no fade.

Gaps

  • Orange: keep #FF6C10 or switch to the game's own orange (#EF8532 on Commendations, #F0803E on the Manhunt screen). Undecided.
  • Climax week: the season finale is one mission, not three tasks. Shown as a single step; wording not yet written.
  • Between seasons: what Done says when there is no Manhunt for a while.
  • The icon has four quarters for three tasks. Kept on purpose: the icon does not count.

Checklist before shipping a change

  • One text size for tasks, Regular for copy and SemiBold for labels, sentence case, no eyebrows.
  • Orange only on Continue and the Objective label.
  • Spacing on the 8 px grid, square corners.
  • The longest task this week fits above Continue on a phone.
  • This guide updated and rebuilt with make.py.
